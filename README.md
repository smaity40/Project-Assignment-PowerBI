# Restaurant Sales Analysis Dashboard | Power BI

## 📌 Project Overview

This project focuses on analyzing restaurant sales data using Microsoft Power BI. It includes an interactive Power BI project, an Excel dataset, and a project presentation to support data exploration and business reporting.

The goal is to transform raw sales data into meaningful visual insights that can help understand sales performance and support data-driven decision-making.

## 🎯 Project Objectives

- Analyze restaurant sales data to understand business performance.
- Create interactive visualizations and reports using Power BI.
- Explore sales trends and performance across available data categories.
- Present data in a clear and structured dashboard.
- Support business decisions through data visualization.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** — Dashboard development and data visualization
- **Microsoft Excel** — Dataset storage and data preparation
- **Power Query** — Data cleaning and transformation, where applicable
- **DAX** — Measures and calculations, where applicable

## 🔍 Project Workflow

1. **Data Understanding:** Review the available restaurant sales dataset.
2. **Data Preparation:** Inspect the data and prepare it for analysis.
3. **Data Modeling:** Organize the data for reporting, where required.
4. **Dashboard Development:** Build visualizations and reports in Power BI.
5. **Analysis:** Explore sales performance and patterns in the available data.
6. **Presentation:** Summarize the project and its findings.

## 📊 Key Features

- Power BI report development
- Restaurant sales data analysis
- Interactive data visualization
- Structured business reporting
- Excel-based data source
- Project presentation

## 💡 Business Value

This project demonstrates how business data can be organized and visualized to make sales information easier to understand. The dashboard can support performance monitoring and help identify patterns that may require further investigation.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Install [Microsoft Power BI Desktop](https://powerbi.microsoft.com/desktop/).
3. Open `Restaurant_Sales.pbip` using Power BI Desktop.
4. If prompted, configure the data source using `Project Sales Data.xlsx`.
5. Refresh the data if necessary.
6. Explore the report and its visualizations.

**Note:** The exact setup may depend on the saved data-source paths and Power BI project configuration.
